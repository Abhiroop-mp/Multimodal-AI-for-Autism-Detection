# Multimodal AI for Autism Detection

A comprehensive web platform for autism detection and therapy management, featuring ML-powered game recommendations and patient progress tracking.

## 🌐 Live Demo
**Hosted on GitHub Pages**: [https://abhiroop-mp.github.io/Multimodal-AI-for-Autism-Detection/](https://abhiroop-mp.github.io/Multimodal-AI-for-Autism-Detection/)

## 🚀 Features

### 🔐 Authentication System
- Secure login with role-based access
- Parent, therapist, and admin dashboards
- Session management and security

### 🎮 Therapeutic Games (31 Games)
- **Attention & Focus**: attention-control, cognitive-flexibility
- **Emotional Regulation**: emotion-regulation, calm-down
- **Social Skills**: conversation-practice, social-skills-training
- **Cognitive Skills**: memory-match, pattern-recognition, problem-solving
- **Sensory Integration**: sensory-integration, texture-play, sound-discovery
- **Life Skills**: time-management, goal-setting, routine-building

### 🤖 ML-Powered Recommendations
- Age-appropriate game suggestions
- Personalized therapy plans
- Progress tracking and analytics

### 📊 Patient Management
- Comprehensive patient profiles
- Progress monitoring
- Assessment results tracking

## 🛠️ Technology Stack

### Frontend
- **HTML5/CSS3/JavaScript** - Core web technologies
- **Font Awesome** - Icons and UI components
- **Responsive Design** - Mobile-friendly interface

### Backend
- **Node.js/Express.js** - Server and API
- **MongoDB/Mongoose** - Database management
- **JWT** - Authentication and security
- **Multer** - File upload handling

### Machine Learning
- **Python/Scikit-learn** - ML algorithms
- **TensorFlow** - Neural networks
- **Pandas/NumPy** - Data processing

## 🎯 Quick Start

### 🌐 Access Live Application
1. Visit: [https://abhiroop-mp.github.io/Multimodal-AI-for-Autism-Detection/](https://abhiroop-mp.github.io/Multimodal-AI-for-Autism-Detection/)
2. Login with demo credentials
3. Explore dashboards and games

### 💻 Local Development
```bash
# Clone repository
git clone https://github.com/Abhiroop-mp/Multimodal-AI-for-Autism-Detection.git
cd Multimodal-AI-for-Autism-Detection

# Start backend server
cd backend
npm install
npm start

# Open loginpage.html in browser
# Or use live server for frontend
```
